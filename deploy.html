Lab Activity 2

Deploy this site on Netlify

Netlify hosts the HTML frontend. The Flask backend is optional and only runs on your computer. Follow these steps after the repo is on GitHub.

1

Create a Netlify account

Go to app.netlify.com and sign up. Signing in with GitHub is the fastest path.

2

Log in

After login you land on the team overview. Click Add a new project (or Add new site).

3

Import from GitHub

Choose Import an existing project, then click GitHub. Authorize Netlify if GitHub asks.

4

Select this repo

Pick Lab-Activity-2--Deploying-a-Website-Using-Netlify. If you are deploying from the session branch, select arena/01a0dcd5-lab-activity-2-deploying-a-web.

5

Configure the build

Publish directory: . (site root). Build command: leave empty, or keep the echo command in netlify.toml. Then click Deploy site.

6

Wait for the build

Netlify copies the HTML, CSS, and JS. There is no Node build. It usually finishes in under a minute.

7

Open the live URL

On the site overview, copy the generated URL. Rename the site under Site configuration → Change site name if you want something like pyworkshop-fundano.

Settings that matter

Publish directory: .

Build command: none required

Python / Flask: not used on Netlify. The quiz still works in the browser.

Why this works on Netlify

Netlify is built for static files and Git deploys. This tutorial is already static HTML, so linking the GitHub repo is enough. The embedded compiler loads from OneCompiler inside an iframe.
