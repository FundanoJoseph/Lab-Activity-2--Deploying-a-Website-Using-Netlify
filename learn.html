Lesson 01

Hello, World

Python is a beginner-friendly language used in web apps, data, and automation. Your first program prints text to the screen.

print("Hello, World!")
print("Welcome to PyWorkshop.")

Each print() call writes one line. Try it in the compiler.

Lesson 02

Variables

A variable is a labeled box that holds a value. In Python you do not declare a type — you just assign.

name = "Joseph"
age = 20
gpa = 1.75
is_student = True

print(name, age, gpa, is_student)

Lesson 03

Data types

str int float bool

Use type() to inspect a value, and int(), str(), or float() to convert.

value = "42"
print(type(value))
number = int(value)
print(number + 8)

Lesson 04

Input and output

input() reads text from the user. Convert it if you need a number.

name = input("What is your name? ")
print("Nice to meet you,", name)

In the online compiler, the input box appears when the program calls input().

Lesson 05

Decisions

Use if, elif, and else to choose a path. Indentation (4 spaces) is part of the syntax.

score = 88

if score >= 90:
    print("Excellent")
elif score >= 75:
    print("Good job")
else:
    print("Keep practicing")

Lesson 06

Loops

for repeats over a sequence. while repeats until a condition is false.

for n in range(1, 6):
    print("Count:", n)

total = 0
i = 1
while i <= 5:
    total += i
    i += 1
print("Sum:", total)

Lesson 07

Lists

A list stores an ordered collection. Index from 0. append() adds an item at the end.

langs = ["Python", "HTML", "CSS"]
langs.append("JavaScript")

for lang in langs:
    print("I am learning", lang)

Lesson 08

Functions

Functions package reusable work. def names the function; return sends a value back.

def greet(name):
    return f"Hello, {name}! Ready to code?"

print(greet("Joseph"))
print(greet("classmate"))
